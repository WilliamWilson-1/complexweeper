HOW TO PLAY

从扫雷，到复数扫雷。

目标很简单：翻开所有没有雷的格子。

四种雷，如何变成线索？

圆复数模式有 +1、−1、+i、−i 四种雷。将某格周围八格的雷相加得到 a + bi，该格显示 √(a² + b²)。例如 +1 和 +i 得到 √2，+1 和 −1 则得到 0。

空白表示周围完全无雷；0 表示有雷但合成值为零。自动展开只沿空白格扩散，不会把 0 当成安全空白。

双曲复数模式

把 i 换成满足 j² = +1 的 j，显示值变成 √(a² − b²)。当 a² − b² 为负数时，用 i 表示形式平方根，例如 √(−3) 显示为 √3i。注意：雷的单位是 j，负值线索的后缀是 i。

标记与展开

电脑左键翻开，右键按「空 → +1 → −1 → +i / +j → −i / −j → 空」循环插旗。也可以先选择一种旗帜，在「标记」模式点击格子；再次点击相同旗帜可移除。手机支持长按插入当前选中的旗帜。

点击已经翻开的数字，可以尝试展开周围未标记格。圆复数要求旗帜总数与实际雷数相同，实雷与虚雷的数量相符或互换；双曲复数要求旗帜总数相同，并且实部、j 部的净和绝对值分别相符。这与原项目当前代码一致。

展开判据通过，并不保证旗帜位置正确；错误的位置依然可能引爆雷。结局会展示全部雷型。✓ 分为「完全正确」和「组合相符」：后者要求雷的位置正确，附近至少有一个已完整标记的数字能被旗帜组合解释，并且其他已翻开的相邻线索仍可成立。它不要求每颗雷与实际正负、实虚完全相同。? 表示缺少完整组合，暂时无法验证；× 表示标在安全格或与线索冲突。

类型判断与抵消对

圆复数模式下，√2 的净实部、净虚部绝对值均为 1。周围恰好两颗雷时必须一实一虚；雷更多时还可以有抵消对。数字 0 要求实部、虚部分别正负抵消，可以有多对。双曲模式的 0 要求实部、j 部净和绝对值相等，一实一 j 也可以成立。

结算中的「组合相符」按已翻开的局部线索验证，不代表唯一解，也不改变原版的展开判据。未标出的雷保留未知类型；不会因缺少信息就把猜测直接判对。

快捷键与小提示

D 切换翻开，F 切换标记，1–4 选择旗帜并进入标记模式；棋盘内方向键移动，Enter / 空格执行当前操作，R 重新开始，Esc 关闭说明。首次翻开时，该格及其周围八格保证无雷。各类雷总数在开局后公开，侧栏显示「总数 − 已插旗数」，可以为负。

本版本未使用无猜算法，部分局面可能需要猜测。最佳用时仅保存在当前浏览器中。
